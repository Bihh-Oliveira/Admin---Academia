# 🏋️ Academia - Admin

Um sistema voltado para a gestão de academias, com foco em organização, praticidade e uma experiência intuitiva para administradores e alunos.

## 📌 Sobre o projeto

É uma plataforma criada para organizar e centralizar a gestão de uma academia, permitindo o **controle de dados importantes como alunos cadastrados, professores, planos e outras informações administrativas.**

O objetivo do projeto é tornar os processos mais simples, reduzindo controles manuais e oferecendo uma experiência mais organizada para os responsáveis pela administração.

## 🚀 Funcionalidades

- [x] Cadastro e gerenciamento de alunos
- [x] Controle de professores
- [x] Visualização e organização de informações dos usuários
- [x] Interface administrativa intuitiva
- [x] Controle de pagamentos e planos
- [x] Dashboard com métricas da academia
- [x] Controle de alunos por status (ativo, inativo ou bloqueado)
- [x] Sistema de avisos internos da academia (avisos, atualizações, manutenções, etc.)
